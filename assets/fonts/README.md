## OFL.txt について

- 本文は SIL OFL 1.1 の公式の文面のまま変えていない。取得元は https://raw.githubusercontent.com/coz-m/MPLUS_FONTS/master/OFL.txt。
- 先頭の著作権行だけ、同梱フォントの表記「Copyright 2016 The Rounded M+ Project Authors.」に差し替えた。取得元の OFL.txt は新しい M+ FONTS 用で「Copyright 2021 The M+ FONTS Project Authors」だったため。Google Fonts の `ofl/mplusrounded1c/` には OFL.txt 自体が無い。
- 確認した根拠: 同梱の ttf の name テーブル（ID 0 が上の著作権表記、ID 14 のライセンス URL が http://scripts.sil.org/OFL）、Google Fonts の METADATA.pb（license "OFL"、同じ著作権表記）。
- Reserved Font Name: 同梱フォントの name テーブルにも、OFL.txt の著作権行にも、Reserved Font Name の指定は見当たらなかった。
- Rounded M+ の公式の原文（2016 年の表記つき）が見つかれば、OFL.txt をそれに差し替える。
